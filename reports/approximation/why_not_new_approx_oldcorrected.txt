\paragraph{Corrected score, stated first.}
At window $w$, score a candidate right direction $v\in\mathbb S^{d-1}$ by
\begin{align}
\operatorname{score}_w(v)
:=
\psi_{\mathrm{old}}(v)+\psi_{\mathrm{new}}(v),
\end{align}
where
\begin{align}
\psi_{\mathrm{old}}(v)
&:=
\|Bv\|_2^2
\left(\frac{n_{\mathrm{seen}}}{n}\right)^{
-\frac{h_2^{(R)}(v)}{4\log s}
},
\\
\psi_{\mathrm{new}}(v)
&:=
\|A_wv\|_2^2
\left(\frac{k}{n_w}\right)^{
-\frac{h_2^{(w)}(v)}{4\log k}
}.
\end{align}
Here $\psi_{\mathrm{old}}$ is the corrected contribution from the old sketch
and old row memory, while $\psi_{\mathrm{new}}$ is the corrected contribution
from the current raw window. If this is the first window, or if no old
sketch/sample is available, set $\psi_{\mathrm{old}}(v)=0$. The rest of this
note defines the symbols and explains the entropy corrections.

\paragraph{Notation in detail.}
Let $\mathrm{row}(X)$ denote the number of rows of a matrix $X$. Let
\begin{align}
A \in \mathbb R^{m\times d}
\end{align}
be the full data matrix, let $A_w$ denote the current row-window, and let
$B \in \mathbb R^{r\times d}$ denote the sketch carried from the previous
windows. In addition to the sketch, carry a small row sample of old data
\begin{align}
R \in \mathbb R^{s\times d}.
\end{align}
Write
\begin{align}
A_w &\in \mathbb R^{k\times d},
\qquad
k = \mathrm{row}(A_w),
\qquad
k>1,
\\
n_w &:= \text{(\# rows in current window)} + \text{(\# rows not yet seen after this window)},
\\
n_{\mathrm{seen}} &:= \text{\# raw rows represented by the old sketch/sample before this window},
\\
n &:= \text{total number of rows in the full matrix or stream},
\\
v &\in \mathbb S^{d-1}.
\end{align}
Assume
\begin{align}
s>1,\qquad n_{\mathrm{seen}}>1,\qquad n>1,
\end{align}
whenever an old contribution is present.

For a nonzero response vector $y$, write
\begin{align}
h_2\left(\frac{y}{\|y\|_2}\right)
=
-\log\left(\frac{\|y\|_4^4}{\|y\|_2^4}\right)
=
4\log\|y\|_2 - 4\log\|y\|_4.
\end{align}

\paragraph{Explanation of the corrected score.}
The old sketch preserves only quadratic energy, so the old term should not be
left as a purely quadratic contribution while the new term receives an entropy
correction. The corrected score therefore uses the sketch for old energy and
the row sample $R$ for a direction-dependent proxy of old entropy.

For the old rows, define
\begin{align}
E_{\mathrm{old}}(v)
&:=
\|Bv\|_2^2,
\\
y_R(v)
&:=
Rv,
\\
h_2^{(R)}(v)
&:=
-\log\left(\frac{\|Rv\|_4^4}{\|Rv\|_2^4}\right).
\end{align}
The sample entropy is not treated as the true old entropy. Instead, use the
same normalized-entropy scaling as in the window derivation:
\begin{align}
\frac{h_2(\text{old full response})}{\log n_{\mathrm{seen}}}
\approx
\frac{h_2^{(R)}(v)}{\log s}.
\end{align}
Thus
\begin{align}
h_2(\text{old full response})
\approx
h_2^{(R)}(v)\frac{\log n_{\mathrm{seen}}}{\log s}.
\end{align}
The row sample is used only to approximate the normalized old entropy. The old
rows themselves occupy the fraction $n_{\mathrm{seen}}/n$ of the full matrix,
so the old contribution is
\begin{align}
\psi_{\mathrm{old}}(v)
:=
E_{\mathrm{old}}(v)
\left(\frac{n_{\mathrm{seen}}}{n}\right)^{
-\frac{h_2^{(R)}(v)}{4\log s}
}.
\end{align}

For the current window, define
\begin{align}
h_2^{(w)}(v)
:=
h_2\left(\frac{A_wv}{\|A_wv\|_2}\right)
=
-\log\left(\frac{\|A_wv\|_4^4}{\|A_wv\|_2^4}\right).
\end{align}
The new contribution is
\begin{align}
\psi_{\mathrm{new}}(v)
:=
\|A_wv\|_2^2
\left(\frac{k}{n_w}\right)^{-\frac{h_2^{(w)}(v)}{4\log k}}.
\end{align}
There is no additional $\left(k/n_w\right)^{1/4}$ prefactor in this corrected
score.

The final score is
\begin{align}
\operatorname{score}_w(v)
:=
\psi_{\mathrm{old}}(v)+\psi_{\mathrm{new}}(v).
\end{align}
If there is no old sketch/sample, set $\psi_{\mathrm{old}}(v)=0$.

\paragraph{Algorithm overview.}
The forget method processes the matrix one row-window at a time.

For the first window, there is no previous sketch and no old row sample, so
\begin{align}
B=0,\qquad R=\varnothing,\qquad \psi_{\mathrm{old}}(v)=0,
\end{align}
and the score is just
\begin{align}
\operatorname{score}_1(v)
=
\psi_{\mathrm{new}}(v).
\end{align}
Compute retained directions $v_1,\dots,v_r$ sequentially by solving
\begin{align}
v_j
\in
\operatorname*{arg\,max}_{v\in\mathbb S^{d-1},\ v_i^\top v = 0\ \forall i<j}
\operatorname{score}_1(v).
\end{align}
Collecting them gives a retained right basis
\begin{align}
V_{\mathrm{hat}} = [v_1,\dots,v_r].
\end{align}
With the current carried operator $M=A_1$, form
\begin{align}
Y = MV_{\mathrm{hat}},
\qquad
U_{\hat{}} = \operatorname{orth}(Y),
\end{align}
compute the SVD of
\begin{align}
U_{\hat{}}^\top M = U_{\mathrm{small}}\Sigma V_{\mathrm{new}}^\top,
\end{align}
and carry the sketch
\begin{align}
B_{\mathrm{next}} = \Sigma V_{\mathrm{new}}^\top.
\end{align}
Also update the old-row memory $R_{\mathrm{next}}$ from the rows seen so far.
The row memory should contain a uniform reservoir component for coverage and,
optionally, a small high-response component selected by large responses on
current sketch directions. The high-response component is intended to reduce
the chance that rare large rows dominating the $\ell_4$ response are absent
from the memory.

For a later window $w$, the input state is the carried sketch
$B^{(w-1)}=\Sigma_{w-1}V_{w-1}^\top$ and the old row memory $R^{(w-1)}$. The
method optimizes the corrected objective $\operatorname{score}_w(v)$ above and
again computes orthonormal retained directions sequentially by solving
\begin{align}
v_j^{(w)}
\in
\operatorname*{arg\,max}_{v\in\mathbb S^{d-1},\ (v_i^{(w)})^\top v = 0\ \forall i<j}
\operatorname{score}_w(v).
\end{align}
After selecting the new right space, it converts that space into the
left-projected carry sketch. With
\begin{align}
\widehat V_w=[v_1^{(w)},\dots,v_r^{(w)}],
\qquad
M_w :=
\begin{pmatrix}
B^{(w-1)}\\
A_w
\end{pmatrix},
\end{align}
form
\begin{align}
Y_w := M_w\widehat V_w,
\qquad
U_{\hat{},w} := \operatorname{orth}(Y_w),
\end{align}
and compute
\begin{align}
U_{\hat{},w}^\top M_w = U_{\mathrm{small},w}\Sigma_w V_w^\top.
\end{align}
The sketch passed to the next window is
\begin{align}
B^{(w)}=\Sigma_wV_w^\top.
\end{align}
The row memory is also updated so that $R^{(w)}$ samples from the raw rows seen
through window $w$, not from the sketch rows.

\paragraph{Derivation of the new-window contribution.}
Let
\begin{align}
z = A_wv
\end{align}
be the response of the current window, and let
\begin{align}
x = Av
\end{align}
be the response of the full remaining population represented by $n_w$. Since
$A_w$ contains only $k=\mathrm{row}(A_w)$ rows, $z$ is a restriction of $x$.
Use the normalized-entropy heuristic
\begin{align}
\frac{h_2\left(\frac{x}{\|x\|_2}\right)}{\log n_w}
\approx
\frac{h_2\left(\frac{z}{\|z\|_2}\right)}{\log k}.
\end{align}
Using
\begin{align}
h_2\left(\frac{y}{\|y\|_2}\right)
=
4\log\|y\|_2 - 4\log\|y\|_4,
\end{align}
and $\|z\|_4 \le \|x\|_4$, we obtain
\begin{align}
4\log\frac{\|z\|_2}{\|x\|_2}
\le
h_2\left(\frac{z}{\|z\|_2}\right)
-
h_2\left(\frac{x}{\|x\|_2}\right).
\end{align}
Substituting the normalized-entropy scaling gives
\begin{align}
\log\frac{\|z\|_2}{\|x\|_2}
\lesssim
-\frac{h_2\left(\frac{z}{\|z\|_2}\right)}{4}\frac{\log(n_w/k)}{\log k},
\end{align}
hence
\begin{align}
\frac{\|A_wv\|_2}{\|Av\|_2}
\lesssim
\left(\frac{k}{n_w}\right)^{
\frac{h_2\left(\frac{A_wv}{\|A_wv\|_2}\right)}{4\log k}
}.
\end{align}
This motivates the reciprocal entropy factor
\begin{align}
\left(\frac{k}{n_w}\right)^{
-\frac{h_2\left(\frac{A_wv}{\|A_wv\|_2}\right)}{4\log k}
}.
\end{align}
Unlike the earlier simplified score, the corrected score does not add the
flat-case prefactor $\left(k/n_w\right)^{1/4}$. The missing information in the
old term is handled directly by the old row-sample entropy proxy, rather than
by a fixed rebalance of the new term.

\paragraph{Derivation of the old contribution.}
The sketch gives the old retained energy
\begin{align}
E_{\mathrm{old}}(v)=\|Bv\|_2^2.
\end{align}
It does not give row-level entropy. The row memory $R$ supplies a proxy
\begin{align}
h_2^{(R)}(v)
=
4\log\|Rv\|_2 - 4\log\|Rv\|_4.
\end{align}
Under normalized-entropy scaling,
\begin{align}
h_2^{(\mathrm{old})}(v)
\approx
h_2^{(R)}(v)\frac{\log n_{\mathrm{seen}}}{\log s}.
\end{align}
Applying the same reciprocal entropy correction at the old-row fraction
$n_{\mathrm{seen}}/n$ gives
\begin{align}
\psi_{\mathrm{old}}(v)
=
\|Bv\|_2^2
\left(\frac{n_{\mathrm{seen}}}{n}\right)^{
-\frac{h_2^{(R)}(v)}{4\log s}
}.
\end{align}
Thus the old term now has the same structure as the new term: retained energy
multiplied by a direction-dependent entropy correction.

\paragraph{Simplified form.}
Define
\begin{align}
c_w
&:=
\frac{\log(k/n_w)}{\log k},
\\
c_{\mathrm{old}}
&:=
\frac{\log(n_{\mathrm{seen}}/n)}{\log s}.
\end{align}
Then
\begin{align}
\psi_{\mathrm{new}}(v)
&=
\|A_wv\|_2^{2-c_w}\|A_wv\|_4^{c_w},
\\
\psi_{\mathrm{old}}(v)
&=
\|Bv\|_2^2\|Rv\|_2^{-c_{\mathrm{old}}}\|Rv\|_4^{c_{\mathrm{old}}}.
\end{align}
Therefore
\begin{align}
\operatorname{score}_w(v)
=
\|Bv\|_2^2\|Rv\|_2^{-c_{\mathrm{old}}}\|Rv\|_4^{c_{\mathrm{old}}}
+
\|A_wv\|_2^{2-c_w}\|A_wv\|_4^{c_w}.
\end{align}
When $k<n_w$ and $n_{\mathrm{seen}}<n$, both $c_w$ and
$c_{\mathrm{old}}$ are nonpositive, so high-entropy responses are boosted by
the same normalized-entropy mechanism in both old and new contributions.

\paragraph{Exact gradient.}
Let
\begin{align}
y_B := Bv,\qquad y_R := Rv,\qquad z := A_wv,
\end{align}
and assume the denominators below are nonzero.

For the old contribution,
\begin{align}
\log\psi_{\mathrm{old}}(v)
=
\log\|Bv\|_2^2
-c_{\mathrm{old}}\log\|Rv\|_2
+c_{\mathrm{old}}\log\|Rv\|_4.
\end{align}
Differentiating gives
\begin{align}
\nabla\log\psi_{\mathrm{old}}(v)
=
2\frac{B^\top Bv}{\|Bv\|_2^2}
-c_{\mathrm{old}}\frac{R^\top Rv}{\|Rv\|_2^2}
+c_{\mathrm{old}}R^\top\left(\frac{(Rv)^{\odot 3}}{\|Rv\|_4^4}\right).
\end{align}
Hence
\begin{align}
\nabla\psi_{\mathrm{old}}(v)
=
\psi_{\mathrm{old}}(v)
\left[
2\frac{B^\top Bv}{\|Bv\|_2^2}
-c_{\mathrm{old}}\frac{R^\top Rv}{\|Rv\|_2^2}
+c_{\mathrm{old}}R^\top\left(\frac{(Rv)^{\odot 3}}{\|Rv\|_4^4}\right)
\right].
\end{align}

For the new-window contribution,
\begin{align}
\log\psi_{\mathrm{new}}(v)
=
(2-c_w)\log\|A_wv\|_2
+c_w\log\|A_wv\|_4.
\end{align}
Differentiating gives
\begin{align}
\nabla\log\psi_{\mathrm{new}}(v)
=
(2-c_w)\frac{A_w^\top A_wv}{\|A_wv\|_2^2}
+c_w A_w^\top\left(\frac{(A_wv)^{\odot 3}}{\|A_wv\|_4^4}\right).
\end{align}
Hence
\begin{align}
\nabla\psi_{\mathrm{new}}(v)
=
\psi_{\mathrm{new}}(v)
\left[
(2-c_w)\frac{A_w^\top A_wv}{\|A_wv\|_2^2}
+c_w A_w^\top\left(\frac{(A_wv)^{\odot 3}}{\|A_wv\|_4^4}\right)
\right].
\end{align}

Therefore the full Euclidean gradient is
\begin{align}
\nabla \operatorname{score}_w(v)
=
\nabla\psi_{\mathrm{old}}(v)+\nabla\psi_{\mathrm{new}}(v).
\end{align}
Equivalently,
\begin{align}
\nabla \operatorname{score}_w(v)
=
&
\psi_{\mathrm{old}}(v)
\left[
2\frac{B^\top Bv}{\|Bv\|_2^2}
-c_{\mathrm{old}}\frac{R^\top Rv}{\|Rv\|_2^2}
+c_{\mathrm{old}}R^\top\left(\frac{(Rv)^{\odot 3}}{\|Rv\|_4^4}\right)
\right]
\\
&+
\psi_{\mathrm{new}}(v)
\left[
(2-c_w)\frac{A_w^\top A_wv}{\|A_wv\|_2^2}
+c_w A_w^\top\left(\frac{(A_wv)^{\odot 3}}{\|A_wv\|_4^4}\right)
\right].
\end{align}

\paragraph{Expanded old-gradient form.}
Sometimes it is numerically preferable to expose the quadratic sketch-energy
gradient instead of using the logarithmic form. Let
\begin{align}
\phi_R(v)
:=
\|Rv\|_2^{-c_{\mathrm{old}}}\|Rv\|_4^{c_{\mathrm{old}}},
\qquad
E_{\mathrm{old}}(v):=\|Bv\|_2^2.
\end{align}
Then
\begin{align}
\psi_{\mathrm{old}}(v)=E_{\mathrm{old}}(v)\phi_R(v),
\end{align}
and
\begin{align}
\nabla\psi_{\mathrm{old}}(v)
=
2\phi_R(v)B^\top Bv
+
E_{\mathrm{old}}(v)\phi_R(v)
\left[
-c_{\mathrm{old}}\frac{R^\top Rv}{\|Rv\|_2^2}
+c_{\mathrm{old}}R^\top\left(\frac{(Rv)^{\odot 3}}{\|Rv\|_4^4}\right)
\right].
\end{align}
This form remains meaningful when $\|Bv\|_2$ is zero, provided the old
entropy proxy is well-defined.

\paragraph{Stored-basis form.}
If
\begin{align}
B = SV^\top,
\qquad
V=[v_1,\dots,v_r],
\qquad
S=\operatorname{diag}(s_1,\dots,s_r),
\end{align}
then
\begin{align}
\|Bv\|_2^2
=
\sum_{j=1}^r s_j^2(v_j^\top v)^2,
\qquad
B^\top Bv
=
\sum_{j=1}^r s_j^2(v_j^\top v)v_j.
\end{align}
Thus the expanded old-gradient term may be written as
\begin{align}
\nabla\psi_{\mathrm{old}}(v)
=
2\phi_R(v)\sum_{j=1}^r s_j^2(v_j^\top v)v_j
+
\psi_{\mathrm{old}}(v)
\left[
-c_{\mathrm{old}}\frac{R^\top Rv}{\|Rv\|_2^2}
+c_{\mathrm{old}}R^\top\left(\frac{(Rv)^{\odot 3}}{\|Rv\|_4^4}\right)
\right].
\end{align}
The full gradient is this old term plus $\nabla\psi_{\mathrm{new}}(v)$.

\paragraph{Optimization problem.}
To extract a direction, solve
\begin{align}
\max_{v \in \mathbb S^{d-1},\ Q^\top v = 0}\operatorname{score}_w(v),
\end{align}
where the columns of $Q$ are the previously accepted directions.

\paragraph{Projected full-gradient ascent.}
Use the exact gradient of the corrected score. Project it onto the feasible
tangent space:
\begin{align}
g_{\mathrm{tan}}(v)
:=
\left(I-QQ^\top-vv^\top\right)\nabla \operatorname{score}_w(v).
\end{align}
Then take
\begin{align}
\widetilde v^{+} = v + \eta\, g_{\mathrm{tan}}(v),
\qquad
v^{+} = \frac{(I-QQ^\top)\widetilde v^{+}}{\|(I-QQ^\top)\widetilde v^{+}\|_2},
\end{align}
with $\eta>0$ chosen by backtracking line search on the true corrected score.

\paragraph{Basis-expansion interpretation.}
If one is building a local search subspace rather than taking a pure
steepest-ascent step, the new direction added to the basis is the projected
full gradient
\begin{align}
g_{\mathrm{basis}}(v)
:=
\left(I-QQ^\top-vv^\top\right)\nabla \operatorname{score}_w(v).
\end{align}
Thus the basis is enlarged by the actual gradient direction of the corrected
score. The roles of old sketch energy, old sampled entropy, current-window
energy, and current-window entropy are already combined inside this single
full-gradient vector.

In a reduced-subspace version, suppose the current local right search basis is
\begin{align}
Z \in \mathbb R^{d\times q},
\qquad
Z^\top Z=I.
\end{align}
After solving the score problem inside $\operatorname{span}(Z)$, the relevant
expansion residual is the part of the feasible tangent gradient that is not
already represented by this local basis:
\begin{align}
r_Z(v)
:=
\left(I-ZZ^\top\right)
\left(I-QQ^\top-vv^\top\right)
\nabla \operatorname{score}_w(v).
\end{align}
The local basis should be expanded only when this residual is non-negligible.
A natural stopping rule is
\begin{align}
\frac{\|r_Z(v)\|_2}
{\left\|\left(I-QQ^\top-vv^\top\right)\nabla \operatorname{score}_w(v)\right\|_2}
\le \tau,
\end{align}
where $\tau$ is a prescribed tolerance. If the ratio is larger than $\tau$, the
new basis direction should be the normalized residual $r_Z(v)/\|r_Z(v)\|_2$,
optionally followed by Krylov refinements generated from this residual
direction.

\paragraph{Operator extraction from the retained right subspace.}
The implementation does not stop after constructing a right search space.
After the scored directions and any auxiliary directions are assembled into an
orthonormal right basis
\begin{align}
V \in \mathbb R^{d\times r},
\end{align}
with row-wise representation $V^\top = V_t$, it forms
\begin{align}
M_w :=
\begin{pmatrix}
B\\
A_w
\end{pmatrix},
\qquad
Y := M_wV.
\end{align}
It then orthonormalizes the image:
\begin{align}
U_{\hat{}} := \operatorname{orth}(Y) = \operatorname{orth}(M_wV).
\end{align}
Equivalently, this defines the orthogonal projector onto the left image of the
retained right space,
\begin{align}
P_U := U_{\hat{}}U_{\hat{}}^\top.
\end{align}
The algorithm then compresses $M_w$ to this left subspace:
\begin{align}
\widetilde M := U_{\hat{}}^\top M_w,
\end{align}
which is the coordinate representation of $P_U M_w$. Finally it computes
\begin{align}
\widetilde M = U_{\mathrm{small}}\Sigma V_{\mathrm{new}}^\top,
\end{align}
and stores
\begin{align}
U_{\mathrm{proj}} = U_{\hat{}}U_{\mathrm{small}},
\qquad
S=\Sigma,
\qquad
V^\top = V_{\mathrm{new}}^\top.
\end{align}
So the carried singular values and right singular vectors are not merely the
raw scored-plus-auxiliary basis; they are the singular factors of the
left-projected operator $P_U M_w$ restricted to the retained right span.

\paragraph{Why this is the sketch carried into the next window.}
The next window does not receive the raw optimized right basis $V_{\hat{}}$ by
itself. Instead it receives the sketch
\begin{align}
B_{\mathrm{next}} := \Sigma V_{\mathrm{new}}^\top,
\end{align}
where
\begin{align}
U_{\hat{}}^\top M_w = U_{\mathrm{small}}\Sigma V_{\mathrm{new}}^\top
\end{align}
is the SVD of the compressed left-projected operator. Equivalently,
$B_{\mathrm{next}}$ is the norm-preserving right-action representation of
\begin{align}
P_U M_w = U_{\hat{}}U_{\hat{}}^\top M_w.
\end{align}
For any direction $v$,
\begin{align}
\|B_{\mathrm{next}}v\|_2
=
\|\Sigma V_{\mathrm{new}}^\top v\|_2
=
\|P_U M_w v\|_2.
\end{align}
Thus the quadratic energy used in the next old term is exactly the energy of
the retained compressed operator. The additional row memory $R_{\mathrm{next}}$
does not replace this sketch; it supplies only the missing row-level entropy
proxy for the next old contribution.

\paragraph{First-window special case.}
If $B=0$ and $R=\varnothing$, then
\begin{align}
c_1 := \frac{\log(k/n_1)}{\log k},
\end{align}
and
\begin{align}
\operatorname{score}_1(v)
=
\|A_1v\|_2^{2-c_1}\|A_1v\|_4^{c_1}.
\end{align}
The full gradient reduces to
\begin{align}
\nabla \operatorname{score}_1(v)
=
\|A_1v\|_2^{2-c_1}\|A_1v\|_4^{c_1}
\left[
(2-c_1)\frac{A_1^\top A_1v}{\|A_1v\|_2^2}
+c_1 A_1^\top\left(\frac{(A_1v)^{\odot 3}}{\|A_1v\|_4^4}\right)
\right].
\end{align}
There is no $\left(k/n_1\right)^{1/4}$ prefactor.

\paragraph{Practical remarks.}
The objective is nonconvex, so multiple restarts are useful. One should reject
or regularize steps when any of $\|A_wv\|_2$, $\|A_wv\|_4$, $\|Rv\|_2$,
$\|Rv\|_4$, or $\|Bv\|_2$ is numerically tiny in a formula that divides by that
quantity. The expanded old-gradient form avoids division by $\|Bv\|_2^2$, but
the row-sample entropy derivatives still require nontrivial response on the
sample.

The row memory should not be interpreted as a replacement for the old sketch.
The sketch $B$ supplies the retained old energy, while $R$ supplies only a
direction-dependent entropy proxy. A pure reservoir sample gives coverage, but
it can miss rare large rows that dominate $\ell_4$ terms. A practical memory
should therefore combine a uniform reservoir with a small high-response set
selected using current sketch directions.
