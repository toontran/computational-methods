Reading guide:
  - mean_mag      = average per-block ||A_blk v||² (size of block contribution)
  - cov_mag       = stdev/mean of mag across blocks (high = unstable)
  - mean_ent      = average within-block row-entropy of A_blk v / log(hw)
  - H_block_norm  = entropy of mag distribution across blocks / log(K)
                    (1.0 = oracle-like uniform; 0.0 = locked to one block)
  - drift_mag     = mean|Δmag|/mean_mag — first-difference drift speed
  - half_ratio    = mean(mag, second half) / mean(mag, first half)
                    (1.0 = stable; 0.0 = locked to first half; >1 = locked late)
  - slope         = log-magnitude trend per block (large negative = decaying)
