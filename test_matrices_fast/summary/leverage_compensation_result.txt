Leverage compensation result
============================

Date: 2026-04-19

Baseline definition
-------------------
The baseline used in the leverage-compensation comparison is:

  baseline-greedy-oraclewarm

This is the fast static-CEX combined-objective run with greedy rank-by-rank
selection and oracle-projected restart seeds:

  python test_matrices_fast/cex_restricted_space_probe.py \
    --matrix static-cex --n 128 --rank 2 --win 32 \
    --preset fast --seed 0 \
    --score-variant combined \
    --no-oracle-candidate-check \
    --joint-warm-start-oracle

Important settings:

  basis_selection: greedy
  joint_warm_start_oracle: True
  reduced_optimizer: cex
  score_variant: combined
  row_concentration_lambda: 0
  row_leverage_lambda: 0
  q0: 5
  qmax: 200
  dtype: float32
  expansion_direction: residual

In greedy mode, --joint-warm-start-oracle means each greedy direction receives
an oracle-projected restart seed. It is not the joint Stiefel optimizer.

Objective compensation tested
-----------------------------
The leverage-weighted compensation tested was:

  score_reg(v) = score(v) - lambda * sum_i w_i p_i

where:

  p_i = (A_block v)_i^2 / ||A_block v||^2

Two row-weight definitions were tested:

  row-norm:
    w_i proportional to ||A_block[i, :]||^2, normalized to mean 1.

  top-svd:
    w_i equal to row leverage in the top-2 left singular vectors of A_block,
    normalized to mean 1.

Command:

  python test_matrices_fast/try_outside_direction_steering.py --full-stream

Conclusion
----------
The tested leverage compensation did not beat simple row-concentration
regularization.

Row-norm leverage compensation helps slightly over baseline, but the effect is
small and weaker than row concentration.

Top-SVD leverage compensation is too blunt. It improves some first-block oracle
geometry and reduces the row-1/v3 artifact, but it damages the full stream.
This suggests the local top-SVD leverage rows include useful signal, not only
bad transient outside-direction support.

The best current objective compensation for this static-CEX case remains mild
unweighted row-concentration regularization:

  row_concentration_lambda ~= 0.1 to 0.2


Next direction
--------------
If leverage compensation is revisited, use a more selective weight than raw row
norm or block top-SVD leverage. A plausible next diagnostic is to penalize rows
that are both high leverage and anomalously tail-aligned, rather than all local
high-leverage rows.
