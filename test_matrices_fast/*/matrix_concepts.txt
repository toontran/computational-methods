Source

Default parameters
  n = 1024
  r_sig = 2
  alpha_sig = 0.003
  alpha_tail = 0.0145
  tail_scale = 0.99
  sigma1 = 0.991
  v_type = rand

Shape
  A is dense and square:

    A.shape = (n, n)

  With defaults:

    A.shape = (1024, 1024)

Construction
  The generated matrix is SVD-structured:

    A_unpermuted = U * diag(svec) * V'
    A = P * A_unpermuted

  where P is a random row permutation. In code this is written as:

    A_unpermuted = (U * svec[None, :]) @ V.T
    A = A_unpermuted[p, :]

Singular values
  The singular-value vector has a shallow signal block followed by a
  slowly decaying tail:

    sig_block[j]  = sigma1 * j^(-alpha_sig),       j = 1:r_sig
    tail_block[j] = tail_scale * j^(-alpha_tail),  j = 1:(n-r_sig)
    svec = [sig_block, tail_block]
    svec[0] = sigma1

  With the defaults, the leading signal values are very close together and
  the tail starts just below them. This makes the dominant subspace hard to
  separate by singular value magnitude alone.

What is special about U
  U is not sampled as a generic random orthogonal matrix. It is built from a
  deliberately structured prototype U0, then orthonormalized by QR.

  The first r_sig columns of U0 are normalized Hadamard columns:

    U0[:, 0:r_sig] = hadamard(n)[:, 0:r_sig] / sqrt(n)

  These signal directions are dense, flat, and incoherent across rows: every
  row has equal-magnitude participation in the signal columns.

  The remaining columns are tail directions with a near-coordinate structure.
  For each tail column j >= r_sig:

    U0[j-r_sig, j] = sqrt(1 - r_sig / n)
    U0[n-r_sig:n, j] = 1 / sqrt(n)

  So each tail column has one large coordinate plus small shared mass in the
  final r_sig rows. This creates many localized tail directions while coupling
  them through a small common row support.

  Finally:

    U, _ = qr(U0)

  The first r_sig signs are flipped if needed so they remain aligned with the
  original Hadamard signal columns. The result is an orthonormal left singular
  basis whose leading directions are dense Hadamard-like signals and whose
  trailing directions come from a structured sparse/localized tail.

Right singular vectors V
  V depends on v_type:

    id    -> V = identity
    U     -> V = U
    rand  -> V = qr(randn(n, n))

  The default run uses v_type = rand, so the right singular vectors are a
  random orthonormal basis.

Streaming layout used by the script
  Rows of A are processed in windows:

    A_block = A[start0:end0, :]

  The default window size is:

    win = 100

  In restricted mode, the working gain matrix is:

    first block:
      M_gain = A_block

    later blocks:
      M_gain = vstack([S_previous * V_previous', A_block])

  With default rank = 2 and win = 100, most later restricted updates use:

    M_gain.shape = (102, 1024)

  The first update uses:

    M_gain.shape = (100, 1024)

Notes
  This matrix is designed to stress streaming low-rank methods: the leading
  left singular directions are globally spread over all rows, the tail is
  structured and close in magnitude, and a row permutation prevents the stream
  from presenting the construction in a convenient order.

# 4. Slowly rotating CEX signal subspace

Instead of abrupt switches, let the signal subspace rotate gradually.

Write the signal block of $U_t$ as
\[
U\_{t,\mathrm{sig}} \in \mathbb{R}^{n \times r\_{\mathrm{sig}}}.
]

Let the tail part stay fixed, and evolve only the signal subspace:
\[
U\_t = \[, U\_{t,\mathrm{sig}} ;; U\_{\mathrm{tail}} ,].
]

A clean update is:
\[
U\_{t+1,\mathrm{sig}} = \operatorname{qf}!\left(U\_{t,\mathrm{sig}} + \eta G\_t\right),
]
where:
- $G_t$ is a small Gaussian perturbation projected orthogonally to the current subspace
- $\operatorname{qf}(\cdot)$ means take the orthonormal factor

More explicitly:
\[
\widetilde U\_{t+1,\mathrm{sig}}
================================

U\_{t,\mathrm{sig}} + \eta (I - U\_{t,\mathrm{sig}}U\_{t,\mathrm{sig}}^\top) Z\_t,
]
\[
U\_{t+1,\mathrm{sig}} = \operatorname{qf}(\widetilde U\_{t+1,\mathrm{sig}}),
]
with $Z\_t \sim N(0,1)^{n \times r\_{\mathrm{sig}}}$.

Then set
\[
A^{(t)} = P\_t U\_t \Sigma\_\star.
]

Parameter:
- $\eta$ = drift speed

Interpretation:
- $\eta = 0$ gives static

- small $\eta$ gives trackable drift
- larger $\eta$ makes the stream effectively nonstationary

This is probably the best continuous-time stress test.

This tests:

- inertia versus responsiveness

# 11. Minimal pseudocode

```python
def generate_time_cex_stream(
    n=1024,
    r_sig=2,
    w=100,
    T=200,
    sigma1=0.991,
    alpha_sig=0.003,
    alpha_tail=0.0145,
    tail_scale=0.99,
    drift_eta=0.01,
    tail_period=40,
    tail_amp=0.05,
    jump_every=None,
    seed=0,
):
    rng = np.random.default_rng(seed)

    U_sig, U_tail = make_initial_cex_left_basis(n, r_sig, rng)
    sig_block = sigma1 * np.arange(1, r_sig + 1) ** (-alpha_sig)
    sig_block[0] = sigma1
    tail_base = np.arange(1, n - r_sig + 1) ** (-alpha_tail)

    blocks = []

    for t in range(T):
        if jump_every is not None and t > 0 and t % jump_every == 0:
            U_sig = fresh_or_rotated_signal_basis(U_sig, rng)

        Z = rng.standard_normal((n, r_sig))
        Z = Z - U_sig @ (U_sig.T @ Z)
        U_sig = qr(U_sig + drift_eta * Z)[0][:, :r_sig]

        U_t = orthonormal_combine(U_sig, U_tail)

        tail_scale_t = tail_scale * (1 + tail_amp * np.sin(2 * np.pi * t / tail_period))
        svec_t = np.concatenate([sig_block, tail_scale_t * tail_base])

        A_t_full = U_t * svec_t[None, :]
        p = rng.permutation(n)
        A_t_full = A_t_full[p, :]
        A_t = A_t_full[:w, :]
        blocks.append(A_t)

    return np.vstack(blocks)
```

# 12. One important implementation note

If you literally build
\[

with $V=I$, then columns are in the canonical basis. That is fine if your claim is that $V$ does not matter.

If you want to avoid any accidental implementation artifact from using $V=I$, use one fixed random orthogonal $V$ for all $t$:
\[
A^{(t)} = P\_t U\_t \Sigma\_t V^\top.
]

That keeps the benchmark generic while still making $V$ irrelevant in principle.
