Input matrix catalog
====================

1. Generated structured CEX matrix
----------------------------------

Source
  cex_restricted_space_probe.py, generate_structured_cex_input(...)

Default parameters
  n = 1024
  r_sig = 2
  alpha_sig = 0.003
  alpha_tail = 0.0145
  tail_scale = 0.99
  sigma1 = 0.991
  v_type = rand

Shape
  A is dense and square:

    A.shape = (n, n)

  With defaults:

    A.shape = (1024, 1024)

Construction
  The generated matrix is SVD-structured:

    A_unpermuted = U * diag(svec) * V'
    A = P * A_unpermuted

  where P is a random row permutation. In code this is written as:

    A_unpermuted = (U * svec[None, :]) @ V.T
    A = A_unpermuted[p, :]

Singular values
  The singular-value vector has a shallow signal block followed by a
  slowly decaying tail:

    sig_block[j]  = sigma1 * j^(-alpha_sig),       j = 1:r_sig
    tail_block[j] = tail_scale * j^(-alpha_tail),  j = 1:(n-r_sig)
    svec = [sig_block, tail_block]
    svec[0] = sigma1

  With the defaults, the leading signal values are very close together and
  the tail starts just below them. This makes the dominant subspace hard to
  separate by singular value magnitude alone.

What is special about U
  U is not sampled as a generic random orthogonal matrix. It is built from a
  deliberately structured prototype U0, then orthonormalized by QR.

  The first r_sig columns of U0 are normalized Hadamard columns:

    U0[:, 0:r_sig] = hadamard(n)[:, 0:r_sig] / sqrt(n)

  These signal directions are dense, flat, and incoherent across rows: every
  row has equal-magnitude participation in the signal columns.

  The remaining columns are tail directions with a near-coordinate structure.
  For each tail column j >= r_sig:

    U0[j-r_sig, j] = sqrt(1 - r_sig / n)
    U0[n-r_sig:n, j] = 1 / sqrt(n)

  So each tail column has one large coordinate plus small shared mass in the
  final r_sig rows. This creates many localized tail directions while coupling
  them through a small common row support.

  Finally:

    U, _ = qr(U0)

  The first r_sig signs are flipped if needed so they remain aligned with the
  original Hadamard signal columns. The result is an orthonormal left singular
  basis whose leading directions are dense Hadamard-like signals and whose
  trailing directions come from a structured sparse/localized tail.

Right singular vectors V
  V depends on v_type:

    id    -> V = identity
    U     -> V = U
    rand  -> V = qr(randn(n, n))

  The default run uses v_type = rand, so the right singular vectors are a
  random orthonormal basis.

Streaming layout used by the script
  Rows of A are processed in windows:

    A_block = A[start0:end0, :]

  The default window size is:

    win = 100

  In restricted mode, the working gain matrix is:

    first block:
      M_gain = A_block

    later blocks:
      M_gain = vstack([S_previous * V_previous', A_block])

  With default rank = 2 and win = 100, most later restricted updates use:

    M_gain.shape = (102, 1024)

  The first update uses:

    M_gain.shape = (100, 1024)

Notes
  This matrix is designed to stress streaming low-rank methods: the leading
  left singular directions are globally spread over all rows, the tail is
  structured and close in magnitude, and a row permutation prevents the stream
  from presenting the construction in a convenient order.


2. Alternative data signals
---------------------------

Source
  cex_restricted_space_probe.py, generate_alternative_data_signals_input(...)

CLI name
  alternative-data-signals

Default benchmark parameters
  n = 128
  rank = 2
  win = 32
  preset = small
  seed = 0

Shape
  A is dense and square:

    A.shape = (n, n)

Construction
  Rows are synthetic observation dates and columns are assets or signal
  buckets from alternative-data sources. The matrix combines web/search,
  card-spend, app-engagement, sentiment, satellite, and coverage exposures
  with delayed source factors, local data-revision shocks, stale update
  stripes, source-dependent noise, and column demeaning.

What this stresses
  The leading search and spend modes are deliberately near-tied and delayed
  relative to each other. Local revisions and stale-source stripes create
  structured transient competitors, so streaming sketches must preserve the
  persistent alternative-data factor rather than chasing update artifacts.

Construction
  Rows are synthetic observation dates and columns are ordered futures

10. Diffuse-diffuse close-gap CEX
---------------------------------

Source
  cex_restricted_space_probe.py, generate_diffuse_diffuse_input(...)

CLI name
  diffuse-diffuse

Default parameters
  n = 1024
  r_sig = 2
  alpha_sig = 0.003
  alpha_tail = 0.0145
  tail_scale = 0.99
  sigma1 = 0.991
  v_type = rand

Shape
  A is dense and square:

    A.shape = (n, n)

Construction
  Minimal perturbation of static-cex. Build

    A_unpermuted = U * diag(svec) * V'
    A = P * A_unpermuted

  with the same Hadamard signal columns and the same close-σ spectrum as
  static-cex, but replace the structured spike-localized tail by an
  orthonormalized random Gaussian tail in the subspace orthogonal to the
  signal columns. Specifically:

    U0[:, 0:r_sig] = hadamard(n)[:, 0:r_sig] / sqrt(n)
    G             = randn(n, n - r_sig)
    G            -= U0[:, :r_sig] @ (U0[:, :r_sig]' @ G)   # project out signal
    U0[:, r_sig:] = qr(G)
    U, _          = qr(U0)

  Singular values follow static-cex:

    sig_block[j]  = sigma1 * j^(-alpha_sig),       j = 1:r_sig
    tail_block[j] = tail_scale * j^(-alpha_tail),  j = 1:(n-r_sig)
    svec          = [sig_block, tail_block]
    svec[0]       = sigma1

  so σ_signal ≈ σ_tail as in static-cex. V is a random orthonormal basis by
  default, since theory says V does not affect the streaming recovery
  problem.

What is special about U
  Every column of U — signal and tail alike — is globally spread over all
  rows. There are no spike-localized tail coordinates. The left-side row
  geometry is uniform across all singular directions.

What this stresses
  This is the "both signal and noise are diffuse, with close singular values"
  regime that is absent from the rest of the catalog. Row-entropy carries no
  information because every candidate direction has near-uniform row support,
  and gain is near-tied because σ_signal ≈ σ_tail. It isolates whether a
  combined gain × entropy objective degrades gracefully to gain-only
  behavior when the entropy term becomes uninformative, or starts chasing
  arbitrary diffuse tail directions.


11. Mixed-tail soft close-gap CEX
---------------------------------

Source
  cex_restricted_space_probe.py, generate_mixed_tail_input(..., tail_spikiness=0.25)

CLI name
  mixed-tail-soft

Default parameters
  n = 1024
  r_sig = 2
  alpha_sig = 0.003
  alpha_tail = 0.0145
  tail_scale = 0.99
  sigma1 = 0.991
  v_type = rand
  tail_spikiness = 0.25

Shape
  A is dense and square:

    A.shape = (n, n)

Construction
  Interpolation between diffuse-diffuse and static-cex. The signal columns
  are the same normalized Hadamard columns and the singular-value profile is
  the same close-gap static-cex profile. The tail is built from two tail
  bases in the subspace orthogonal to the signal:

    U_diffuse_tail = qr(projected randn(n, n-r_sig))
    U_spiky_tail   = qr(projected static-cex localized tail)

  Then:

    tail_raw = sqrt(1-tail_spikiness) * U_diffuse_tail
             + sqrt(tail_spikiness)   * U_spiky_tail
    U_tail   = qr(project_out_signal(tail_raw))
    U        = qr([U_sig, U_tail])

What is special about U
  The top signal directions remain fully diffuse. The tail is mostly diffuse
  but has visible localized leverage. In the n=1024, seed=0 structural probe
  using the designed left singular vectors:

    signal rel_H mean       1.000
    first-50 tail rel_H     0.745 mean, 0.721 min
    first-50 tail top1 mass 0.260 mean
    first-50 tail top32     0.405 mean
    first-50 tail r80       263 rows mean

What this stresses
  This is the first "in-between" case: entropy still has some ability to
  penalize the tail, but the tail is far less concentrated than static-cex.
  It tests whether combined/hybrid degrade smoothly as the tail becomes less
  entropy-poor.

  combined entropy multiplier is strong enough to reorder near-tied gain
  candidates when the tail is only moderately localized.

14. Residual panel with spiky idiosyncratic shocks
--------------------------------------------------

Source
  cex_restricted_space_probe.py, generate_residual_spiky_shocks_input(...)

CLI name
  residual-spiky-shocks

Default benchmark parameters
  n = 1024
  rank = 2
  win = 32
  preset = fast
  seed = 0

Shape
  A is dense and square:

    A.shape = (n, n)

Construction
  Counterfactual variant of risk-residual-panel. The factor geometry is
  identical: same two crowding / liquidity residual U columns, same
  sector-grouped V, same structured residual tail, same close-σ signal gap.
  Only the idiosyncratic noise model is changed:

    risk-residual-panel:
      A = vol[t] * (U * svec) V'  +  idio_scale * t5_noise(n, n)

    residual-spiky-shocks:
      A = (U * svec) V'
      for each of n_spike_rows rows chosen uniformly at random:
          support    = random subset of columns (size ~ n / 64)
          direction  = randn(support).normalized
          A[row, support] += spike_amp * direction
      A += noise_floor * randn(n, n)
      A -= A.mean(axis=0)

  The dense heavy-tailed heteroskedastic noise of risk-residual-panel is
  replaced by rare, row-localized spikes on a few random columns, plus a
  tiny dense Gaussian floor for non-degeneracy.

What this stresses
  The pre-shock signal subspace is identical to risk-residual-panel, so the
  same close-σ residual competition between the crowding and liquidity modes
  is present. What changes is the row geometry of the idiosyncratic shock:
  instead of a dense diffuse noise direction that spreads mass evenly across
  rows, the shock is spike-like with concentrated row support. At the tuned
  spike_amp=0.10 setting, the shock can rise into the exact top subspace after
  V_exact is recomputed from the final A, so this matrix is also a probe of
  row-concentrated targets, not only row-concentrated tails.

  Paired with risk-residual-panel this began as a factorial probe:
  combined-score objectives that were defeated on risk-residual-panel because
  the noise direction won on both gain and entropy were expected to recover
  here, because spiky noise loses entropy. The tuned version revealed a sharper
  case: if the spike enters V_exact itself, combined is expected to reject the
  true top direction because the entropy multiplier penalizes row concentration.
